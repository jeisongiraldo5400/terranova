Exportar datos del sistema anterior

Genera un archivo JSON con todo lo guardado en este navegador.

  1. Abra el sistema anterior en este mismo navegador y equipo.
  2. Abra este archivo desde el mismo origen (misma dirección), o pegue el contenido de exportar() en la consola del navegador.
  3. Pulse el botón: se descargará terranova-export.json.
  4. Repita en cada equipo donde se haya usado el sistema: los datos de localStorage no se comparten entre computadores.
