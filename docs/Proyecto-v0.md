# Sistema de Administración de Lotes

## Versión
0.0.1

## Estado
🟡 En desarrollo

---

## Objetivo

Desarrollar una aplicación web para administrar la venta de lotes, clientes, contratos y pagos de una forma sencilla, segura y profesional.

---

## Usuarios

👑 Administrador

👩 Secretaria

👷 Empleado

---

## Reglas del negocio

- El lote mínimo es de 1000 m².
- El precio se negocia con cada cliente.
- El cliente realiza dos pagos:
  - Cuota inicial.
  - Pago final.
- El sistema calculará automáticamente el saldo pendiente.
- Cuando el saldo sea cero, el lote cambiará al estado "Pagado".
